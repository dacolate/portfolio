# Personal Portfolio

My personal developer portfolio, built with Next.js to present my background, skills, services, projects, and contact information.

## Sections

- Home
- Resume
- Services
- Work / projects
- Contact

## Tech Stack

- **Framework:** Next.js 14
- **Frontend:** React 18
- **Styling:** Tailwind CSS
- **UI:** Radix UI, Lucide React
- **Animation:** Framer Motion
- **Carousel / interactive content:** Swiper

## Getting Started

```bash
git clone https://github.com/dacolate/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Purpose

This project serves as a central presentation of my software-development work and professional profile. It is intended to evolve alongside my backend, full-stack, data, and quantitative-finance work.
